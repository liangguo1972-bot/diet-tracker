## 前端需要遵守的结论

1. 保存期间禁用保存按钮。
2. 保存失败保留草稿，但不自动重试。
3. 未登录或权限错误直接回到登录流程，不显示匿名数据。
4. 重新打开或更新餐次前，按接口错误重新读取今天数据。
